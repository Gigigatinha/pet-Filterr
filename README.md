O Pet Finder é um projeto desenvolvido para praticar o consumo de APIs públicas utilizando React, Vite e Axios.As informações sobre as raças são obtidas através da The Dog API, que fornece dados e imagens de diferentes cachorros.

Ultilizei:React, Vite, JavaScript, CSS, Axios, The Dog API.

Link da API utilizada: "https://api.thedogapi.com/v1"
